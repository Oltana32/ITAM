# ITAM System Frontend Implementation Guide

## Overview
This guide provides detailed instructions for updating the frontend components to support the new ITAM enhancements.

## Backend API Changes
The backend has been updated with these key endpoints:

### Reports Endpoints
- `GET /api/saved-reports/generate_asset_report/` - Export asset report as XLSX
- `GET /api/saved-reports/generate_assignment_report/` - Export assignment report as XLSX
- `GET /api/saved-reports/generate_maintenance_report/` - Export maintenance report as XLSX
- `GET /api/saved-reports/generate_license_report/` - Export license report as XLSX

### Notifications Endpoints
- `POST /api/notifications/clear_all/` - Delete all notifications for current user

### Manufacturers Endpoints
- `POST /api/manufacturers/sync_real_manufacturers/` - Sync manufacturers from real data

### Model Updates
- **Assets**: `tag` is now read-only, auto-generated (LAP-0001, DES-0001, etc.)
- **Locations**: Added `city` field with Ethiopian city choices; removed `capacity` field
- **Licenses**: `key` field removed entirely; `vendor` is now a dropdown
- **Notifications**: Added `notification_type`, `message`, related IDs
- **Assignments**: `status` field now supports: active, returned, overdue, available, assigned, retired, disposed, lost, damaged
